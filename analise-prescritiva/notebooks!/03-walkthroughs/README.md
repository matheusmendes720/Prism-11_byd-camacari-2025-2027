# 03-walkthroughs — Walkthrough Visual dos L*

11 documentos narrativos (WL-0 a WL-10) que descrevem cada notebook L* didático em **linguagem executiva**, sem código.

## Estrutura de cada WL

Cada walkthrough tem 7 seções:
1. **Visão geral** do notebook (2 min de leitura)
2. **Estrutura narrativa** (3 min)
3. **Conceitos centrais** (5 min) com fórmulas LaTeX
4. **Outputs e visualizações** (3 min)
5. **Conexão com base D2** (2 min)
6. **Chef's tips** (1 min)
7. **Conclusão + cross-links** (1 min)

## Como usar

Recomendado ler o **WL correspondente ANTES** de executar o L* notebook. Cada WL:
- Lista os conceitos centrais em linguagem executiva
- Mostra as fórmulas-chave com intuição
- Aponta para os docs D2 mais profundos (cross-refs)

Total: 11 WL × ~9 KB cada = **~100 KB de narrativa**.

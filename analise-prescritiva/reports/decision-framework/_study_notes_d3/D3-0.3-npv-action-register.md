## §1. O que é NPV live layer (auto-cálculo contínuo)

### §1.1 Definição

O **NPV live layer** (definido em `D3-NPV-LAYER-SPEC.md`) é um pipeline
automatizado que **recalcula diariamente o NPV de cada prescrição**
(hedge FX, dual-sourcing, defensivo, advocacy, partnerships) com dados
de mercado atualizados. Substitui o cálculo **estático e manual** que o
D2 fazia pontualmente.

### §1.2 Por que é necessário

Do `D3-NPV-LAYER-SPEC.md` §1:

> *"Decisões com dados stale custam caro: NPV de R$ 1bi baseado em
> σ=14% pode ser R$ 0,5bi com σ=20% (sub-otimização de R$ 500M)."*

A sensibilidade do NPV à vol PTAX é grande — uma mudança de σ de 14%
para 20% muda o VaR residual em ~40%. Sem live recalc, o Conselho
decide com números de 6 meses atrás.

## §2. NPV base vs stress vs scenario (3 cenários × 96 combinações)

O NPV live layer calcula **3 cenários macro** × **96 combinações** de
σ PTAX × cenário S3 × status S2. Cada prescrição tem seu próprio
**cálculo de NPV**.

### §2.2 As 96 combinações

A matriz de sensitivity tem **8 valores de σ × 4 cenários S3 × 3 status S2**:

- **σ_values** = [10%, 12%, 14%, 16%, 18%, 20%, 22%, 25%]
- **s3_scenarios** = [Expansão (ViE=25%), Continuidade (ViE=18%),
  RB Parcial (ViE=10%), RB Total (ViE=0%)]
- **s2_status** = [GREEN, AMBER, RED]

Total: 8 × 4 × 3 = **96 cenários por prescrição**.

### §2.3 Exemplo: NPV hedge FX (do `D3-NPV-LAYER-SPEC.md` §3.1)

```python
def hedge_fx_npv(vol30d, sigma, vie_forecast, current_h, h_star):
    # 1. Compute VaR residual (constraint)
    var_fx_p95 = 2.742e9  # R$ 2.742bi (real BCB, σ=14.86%)
    var_residual = var_fx_p95 * (1 - h_star)

    # 2. Compute margin buffer (5% de VGV)
    margin_buffer = 0.05 * 30e9  # R$ 1.5bi (assumindo VGV R$ 30bi)

    # 3. NPV = VaR benefit - cost
    var_benefit = var_fx_p95 * h_star
    premium_cost = 0.01 * h_star * 1.5e9  # 100bps × h* × exposição FX
    npv = var_benefit - premium_cost

    # 4. ROI = NPV / cost
    roi = npv / premium_cost if premium_cost > 0 else 0

    # 5. Saturação: h* = min(constraint, ceiling=95%)
    if h_star >= 0.95:
        constraint_binding = False

    return {
        "npv_R$_M": npv / 1e6,
        "roi_%": roi * 100,
        "var_residual_R$_M": var_residual / 1e6,
        "premium_cost_R$_M": premium_cost / 1e6,
        "var_benefit_R$_M": var_benefit / 1e6,
        "constraint_binding": True,
        "h_star_%": h_star * 100,
    }
```

**Recalc trigger**: PTAX intraday update (4×/dia) ou change em ViE forecast.
